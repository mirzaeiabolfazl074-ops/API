# ⚡ ای‌پی‌آی استور — راهنمای کامل

## 🚀 اجرای محلی

```bash
npm install
npm start
```

سایت روی http://localhost:3000 باز می‌شود.

## 🌐 انتشار آنلاین (رایگان)

### گزینه ۱: Render.com

1. کد را در GitHub آپلود کنید
2. در [render.com](https://render.com) → New → Web Service → ریپازیتوری را انتخاب کنید
3. دستور اجرا: `npm start`
4. دامنه رایگان می‌گیرید: `your-app.onrender.com`

### گزینه ۲: Railway.app

همان فرایند، حتی ساده‌تر.

## 🔍 دیده شدن در گوگل (SEO)

1. دامنه اختصاصی بخرید (مثلاً از nic.ir یا Namecheap)
2. فایل‌های `robots.txt` و `sitemap.xml` را با آدرس دامنه واقعی خود ویرایش کنید
3. در [Google Search Console](https://search.google.com/search-console) سایت را ثبت کنید
4. سایت‌مپ را آنجا ارسال (Submit) کنید
5. کلمات کلیدی فارسی را در `index.html` بخش `<title>` و `description` بهینه کنید
